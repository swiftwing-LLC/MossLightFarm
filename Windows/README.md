# Windows releases · Mosslight Farm 1.1

For a normal Windows 10/11 64-bit installation, share or run `最新版/MosslightFarm-Setup-v1.1-Windows.exe`. It includes the game and its artwork, works without Wallpaper Engine, installs into `%USERPROFILE%\Applications\MosslightFarm\1.1`, and registers **Mosslight Farm | 苔光农场** in Windows Settings → Apps → Installed apps. Uninstalling closes active farm wallpaper builds, removes the installed game and its shortcuts, turns off its startup task, and preserves the normal save at `%USERPROFILE%\Saved Games\MosslightFarm\save.json`.

The wallpaper continues to show movable fields. The separate seed page contains only seed choices, harvest/plant actions, and land purchase; it does not show a field grid. Construction and upgrades pause farm production while they run.

The personal unlimited-coin, one-minute construction build is in `维护版/MosslightFarm-Maintenance-v1.1.zip`. Its save is separate from the normal game. See the archive's `README.txt` before running it as a wallpaper.

`源码` is the single Windows source copy. Older builds are kept under `历史版本`; test results and preview images are under `验证`. The Linux release is maintained separately in `../Linux`.
