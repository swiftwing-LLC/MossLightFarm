# Linux · Mosslight Farm 1.0

下载 [MosslightFarm-Linux-v1.0.tar.gz](最新版/MosslightFarm-Linux-v1.0.tar.gz)，解压后进入文件夹运行：

```sh
./run.sh
```

需要 Python 3 和桌面浏览器。游戏通过仅监听本机的轻量 HTTP 服务离线运行，Chromium 系浏览器以应用窗口打开；Firefox 以独立窗口打开。可运行 `./install.sh` 将游戏添加到用户应用菜单。存档保存在游戏专用浏览器配置中，与日常浏览隔离。

这是可玩的 Linux 游戏窗口，不依赖 Wallpaper Engine。Linux 桌面环境没有统一的动态壁纸托管接口，因此 Linux 版暂不嵌入桌面壁纸。功能包括中英文切换、种植收获、81 块土地扩建、仓库订单、建筑施工停产、可移动田块和建筑、自由漫游动物及流畅雨雪。

`源码` 保存唯一源码；`最新版` 保存给玩家的便携包。Linux 原生桌面实机未能在本开发环境中运行，本版已通过浏览器交互检查、JavaScript 语法与 Python 启动器检查。
