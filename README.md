# 苔光农场 · Mosslight Farm

Windows 1.1 adds a seed-and-actions farm page and is the current Windows release. Version 1.0 is retained as a rollback installer; future releases increment the final digit.

| Platform | Latest artifact | Status |
| --- | --- | --- |
| Windows 10/11 64-bit | [Windows 1.1 installer](Windows/最新版/MosslightFarm-Setup-v1.1-Windows.exe) | Interactive desktop wallpaper; no Wallpaper Engine required |
| Windows personal testing | [Maintenance 1.1 bundle](Windows/维护版/MosslightFarm-Maintenance-v1.1.zip) | Unlimited coins, one-minute building timers, isolated save |
| Linux | [Linux 1.0 portable package](Linux/最新版/MosslightFarm-Linux-v1.0.tar.gz) | Offline game window |
| macOS | [macOS source](macOS-iOS/macOS) | Source requires build and verification on a Mac |
| iOS | [iOS status](macOS-iOS/iOS) | Not developed yet |

Send Windows friends the single installer. Linux users can extract the portable package and run `./run.sh`; see [Linux instructions](Linux/README.md). Each platform stays in its own directory, and older Windows builds are kept in `Windows/历史版本`.
